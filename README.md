# Bike Buyers Sales Dashboard

## Project Overview

This project analyzes customer demographic and behavioral data to identify factors influencing bike purchase decisions. Using Microsoft Excel, I performed data cleaning, data transformation, Pivot Table analysis, and dashboard development to uncover trends across income, age groups, commute distance, education, and regional demographics.

## Dataset

* 1,000+ customer records
* Customer demographics and purchasing behavior
* Fields include income, age, marital status, education, region, commute distance, and bike purchase status

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning
* Dashboard Design

## Key Analysis Performed

### Data Cleaning

* Removed duplicate records
* Standardized marital status and gender values
* Created Age Bracket categories for analysis

### Dashboard Metrics

* Average Income by Purchase Status
* Commute Distance Analysis
* Age Group Analysis

## Key Insights

* Customers who purchased bikes have a higher average income ($57,963) than non-buyers ($54,875).
* Middle-aged customers represent the largest bike-buying demographic.
* Customers with shorter and medium commute distances show stronger bike purchase behavior.
* Income appears to positively influence bike purchase decisions.
